# Intelimaq | Assistência Técnica — PWA

Gerador de mensagens de registro de atendimento técnico para copiar ou compartilhar pelo WhatsApp.

- Tratamento e nome do cliente são opcionais.
- Modelo da máquina, número de série e descrição também são opcionais.
- Técnico responsável: Alison Moura, Jonathan Xavier ou Raphael Soares.
- Não salva histórico nem envia dados para servidor.
- Inclui cache offline após o primeiro acesso.

## Publicação
Envie o conteúdo desta pasta para a raiz do repositório do GitHub Pages, mantendo a pasta `icons`. Se a versão antiga continuar aparecendo, feche e reabra o aplicativo ou atualize a página.
